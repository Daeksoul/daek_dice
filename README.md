# daek_dice

A standalone diceroller script for FiveM, using standard Dungeons & Dragons-style dice.

/roll d20 - Rolls a d20 dice.
/roll 2d6 - Rolls x2 d6 dice.
etc.

Outputs are displayed on-ped and visible to anyone within a small radius to the player.
Range can be changed in the client.lua file.


## Installation

Install daek_dice in the [Standalone] folder to keep things simple!
If you install outside of the [Standalone] folder, make sure 'ensure daek_dice' is in your server startup config.

```txadmin
  ensure daek_dice
```
